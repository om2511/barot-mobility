---

## ✨ સોફ્ટવેરની મુખ્ય સુવિધાઓ (Full CRUD Functions):
- **મારી ગાડીઓ (Vehicles):** નવી ગાડી ઉમેરો (Add), માહિતી સુધારો (Edit/Update), કાઢી નાખો (Delete).
- **મારા ડ્રાઇવરો (Drivers):** નવો ડ્રાઇવર ઉમેરો (Add), પગાર/મોબાઇલ સુધારો (Edit/Update), કાઢી નાખો (Delete).
- **રોજિંદી એન્ટ્રી (Transactions):** ભાડું, CNG ગેસ, સર્વિસ ઉમેરો (Add), સુધારો (Edit/Update), કાઢી નાખો (Delete).
- **ડ્રાઇવર પગાર (Payroll):** વાઉચર બનાવો (Add), એડવાન્સ/બોનસ સુધારો (Edit/Update), કાઢી નાખો (Delete), ચુકતે કરો (Mark Paid).
- **અંગત/ઘર ખર્ચ (Personal Finance):** ઘર કરિયાણું, ફી, SIP ઉમેરો (Add), રકમ સુધારો (Edit/Update), કાઢી નાખો (Delete).
- **એડમિન પ્રોફાઇલ (Admin Profile):** હર્ષ ભાઈનું પૂરું નામ, મોબાઈલ, બિઝનેસનું નામ અને પાસવર્ડ બદલવાની સુવિધા.
